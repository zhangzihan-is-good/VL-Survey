# VL-Survey

The survey's complete English system coding table is available in [Complete_system_coding.xlsx](Complete_system_coding.xlsx). It contains **564 systems and 107 fields** in one worksheet, with one system per row: 238 virtual models and 326 digital twins. Each row includes an article title, publication year, and direct article link.

[Read the column guide online](https://zhangzihan-is-good.github.io/VL-Survey/Coding_table_guide.html) for each column's meaning, possible values, and applicable conditions. The [standalone HTML guide](Coding_table_guide.html) can also be downloaded and opened offline. It supports keyword search and browsing by topic.

Credibility items describe practices reported in the articles. `yes` means the article reports the practice, and `no` means it does not report the practice. `Not applicable` marks a field that does not apply to the model or an unused list position. `Not reported` marks information that the article does not provide. Field-specific definitions are given in the guide.
